Adds a separate Files page inside an active session. Click Files in the viewer toolbar or host sharing banner to browse This computer and Connected computer side by side. Double-click folders, use Up or Locations to navigate, select an item, and copy it to the folder open in the opposite pane. Back to session returns to desktop control while a transfer can continue.

Files and nested folders transfer in both directions, including empty folders and binary files. Progress shows acknowledged bytes and transfer speed. Cancel stops the transfer and removes its partial output; disconnect also cleans partial transfers. Existing destination items are retained and incoming items receive a numbered name. Each nonempty file is SHA-256 checked. Sources changing during reads are rejected.

Transfers use a separate reliable encrypted WebRTC data channel within the existing owned-device session. Main-process filesystem access requires an active session and opaque handles from browsing. Paths are validated, writes are exclusive, symbolic links and special files are not transferred, and no uploaded file is automatically opened. The session approval message now includes file browsing and transfers. OS permissions still apply. Listings show up to 5,000 entries; one folder transfer is limited to 20,000 entries. This preview copies contents and folder structure rather than ownership, ACLs or other filesystem metadata.
